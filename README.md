# 🧺 Washerette Laundry

A modern and responsive laundry service website built using **HTML, CSS, and JavaScript**. The website allows users to explore services, view pricing, and book laundry services through a simple and user-friendly interface.

---

## 🚀 Features

* Responsive design for desktop, tablet, and mobile devices
* Modern navigation bar with smooth section navigation
* Service showcase section
* Pricing table
* Laundry booking form
* Booking confirmation screen
* Clean and attractive UI
* Interactive buttons with hover effects

---

## 🛠️ Technologies Used

* HTML5
* CSS3 (Flexbox & Responsive Design)
* JavaScript (DOM Manipulation)

## ⚙️ How to Run the Project

1. Clone the repository

```bash
git clone <repository-url>
```

2. Open the project folder

```bash
cd Washerette-Laundry
```

3. Open `index.html` in your browser

OR

4. Use VS Code Live Server

* Install the Live Server extension
* Right-click on `index.html`
* Click **Open with Live Server**
